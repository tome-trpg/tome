# 評測結果

這個資料夾放 TOME 的盲評結果（ADR-0065、ADR-0139）。TOME 不內建預設模型，選模型時可以參考這裡的數字。

* 每次盲評一份 Markdown，檔名是日期加供應商，例如 `2026-11-20-anthropic.md`，由 `node tools/eval.ts report` 產生。
* 只有數字與可以重現的設定：每組的平均分數、分數分布、95% 信賴區間、淘汰率、花費與 token，評審的一致性，Q-8 的判定，以及模型、提示與規則包的雜湊。
* 黃金段落只用公開的 ORC 文件與公有領域文本，報告裡只放段落的索引（document 層的 SHA-256、區塊編號、角色與字元數），不放原文與譯文。有同一份 PDF 的人照索引挑得出同樣的段落。
* 分數是一位評審（TOME 的維護者）的判斷，帶個人偏好。
* 商業書不評，也不公開任何商業書的結果。
