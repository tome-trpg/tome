# ADR-0028：第一版只做 CLI，核心寫成函式庫

## 脈絡

人要介入的地方是實體卡審定、校稿、看報告。第一版可以靠檔案與 Obsidian，但審定上千個候選詞時，純文字檔不算好用。

## 決定

1. 第一版只做 CLI。
2. 核心寫成函式庫，CLI 只是外面一層。
3. 之後要加本機網頁介面不用重寫。

## 後果

第一版的審定體驗較陽春。

## 替代方案

**第一版就做本機網頁介面**：範圍明顯變大；**桌面 App**：打包與簽章成本最高；**永遠只有 CLI**：把路堵死；都否決。
