# ADR-0037：主翻譯預設關閉思考

## 脈絡

目前的模型預設開 adaptive thinking，思考計入輸出費，而輸出費本來就占約八成。附錄 A 沒有計入這一塊（[佐證 §1.10](../research/2026-10-31-landscape.md#110-第-4-輪補充)）。

## 決定

1. 主翻譯預設關閉思考，能關的模型就關，不能關的用低 effort。
2. 估價要計入思考成本。
3. 實測後再決定哪些角色值得開。

## 後果

品質影響未量測（H-13）。

## 替代方案

**使用模型預設值**：費用未量測，全書可能明顯超出附錄 A；**依角色分開**：方向正確但沒有實測支持；都否決。
