# ADR-0048：公開規則包的內容與授權

## 脈絡

ORC 要求衍生部分以同樣條款授權，聲明寫漏會自動終止；CC BY 要求署名並標明更動（[佐證 §3.8](../research/2026-10-31-landscape.md#38-開放授權規則包的義務)）。

## 決定

1. `d100-orc` 的目錄用 ORC 授權，`gumshoe-srd` 用 CC BY 3.0，`generic` 用 Apache-2.0。
2. 每個規則包有自己的 `LICENSE` 與 `NOTICE`，內容依各授權的要求。
3. 所有內建包 MUST NOT 暗示官方背書，也不放 Logo 或未授權的具名產品。
4. 雙語範例與譯名只用開放內容與合成文字，譯名自己定，由維護者審過，不抄任何官方中文版的詞表。

## 後果

同一個 repo 有多種授權，根目錄的 `NOTICE` 要說清楚。

## 替代方案

**只用合成文字**：最保守，但範例貼近真實規則文字的程度較低；否決。
