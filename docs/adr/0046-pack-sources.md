# ADR-0046：規則包只來自內建與工作區

## 脈絡

網路安裝會多一個對外出口，也容易變成散布商業內容的管道。本機包可能含有商業書的文字，出版社政策規範的正是公開散布。

## 決定

1. 內建包隨程式發佈，其他規則包放進工作區，同 ID 時本機優先。
2. 第一版沒有網路安裝。
3. 第一版不提供匯出。

## 後果

分享規則包要自己複製檔案。

## 替代方案

**`tome system add <git url>`**：社群包好流通，但多一個對外出口；**去除範例的匯出**：工具本身成了散布管道；都否決。
