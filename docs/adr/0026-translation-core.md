# ADR-0026：翻譯核心

## 脈絡

原設計只做事後檢查，改一個詞就讓全書快取失效。查到的同類工具對佔位符遺失幾乎不處理（[佐證 §1.9](../research/2026-10-31-landscape.md#19-標籤協定與佔位符的前例)）。

## 決定

1. 段落用文字標籤傳送，行內標記對齊 XLIFF 的 `ph`、`pc`；第一版不做 TMX、TBX、XLIFF。
2. 遮蔽規則全部來自規則包。
3. Pass 0 先在本機挖候選詞，只送候選詞與少量上下文。
4. 譯名用提示加驗證，優先序是使用者、本書審定、系列、規則包、LLM 提議。
5. 驗證失敗只重送失敗的單位，到上限標 `FAILED_QA`，MUST NOT 靜默略過。
6. 翻譯記憶的鍵是遮蔽後文字、命中詞條、目標語言、風格版本；短段落加前一段雜湊。
7. 改譯名時替換翻譯記憶，不重翻。
8. 風格依區塊角色。

## 後果

Pass 0 的召回率待驗證（H-11）。

## 替代方案

**JSON schema**：改 schema 會讓快取失效，也不是每家都支援；**硬替換譯名**：LLM 看到混合文字；都否決。
