# ADR-0051：規則包的功能補充

## 脈絡

數值塊的數字最容易被改錯。同一套系統的不同年代戰役，文風也不一樣。

## 決定

1. `roles.yaml` 可以宣告數值塊欄位，標籤用術語翻，數字保留，整塊對得上就不送 LLM。
2. 單書覆寫檔調整年代、基調與額外模式。
3. 實體類別可以設預設代名詞，集合來自目標語言設定檔。
4. `tome probe` 依關鍵詞與骰子格式建議規則包，只建議，不自動套用。

## 後果

欄位化的涵蓋率待驗證（H-15）。

## 替代方案

**數值塊全部送 LLM**：較簡單，但花錢又有改錯數字的風險；否決。
