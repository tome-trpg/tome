# ADR-0060：驗證分級與用語檢查

## 脈絡

重送要花錢，所以只有確定是錯誤的才值得重送。用語檢查有誤報。OpenCC 的 `s2twp` 在字元轉換後會套台灣片語表，可以不花 token 找出疑似大陸用語（[佐證 §3.9](../research/2026-10-31-landscape.md#39-測試工具與語料)）。

## 決定

1. 重送：標記不對應、佔位符遺失、數字不守恆、沒用鎖定譯名、混入簡體字、長度過短。
2. 只報告：疑似大陸用語、機翻腔、長度過長、代名詞與實體卡不符。
3. 用語檢查用 OpenCC 的台灣片語表，目標語言設定檔再放跟團文化有關的詞，誤報進例外清單。
4. 輸出的標題與表格結構要跟 IR 一致，這取代 prompt 的 Markdown AST 守恆。

## 後果

大陸用語不會自動修，要看報告處理。

## 替代方案

**大陸用語也重送**：字典有誤報，會花多餘的費用；**全部只報告**：骰子與數字錯誤要人工修；**只用自訂清單**：要從零累積；**交給 LLM 審稿**：每段都要花 token；都否決。
