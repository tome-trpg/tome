# ADR-0038：拒答是獨立狀態

## 脈絡

恐怖題材可能被內容過濾擋下。Anthropic Batch 的拒答回 `succeeded`，不主動檢查就會把空結果當成功；`general_harms` 連正常內容也可能觸發（[佐證 §1.10](../research/2026-10-31-landscape.md#110-第-4-輪補充)）。

## 決定

1. 拒答是獨立狀態 `REFUSED`，不算 QA 失敗。
2. 轉接層 MUST 檢查各家的拒答訊號。
3. 先改送同供應商的其他模型，整批失敗時對半拆。
4. 跨供應商回退只在設定檔明列時才做。
5. 都失敗就列入交付報告。

## 後果

跨供應商要自己設定，否則部分段落要人工處理。

## 替代方案

**全部交給人工**：恐怖題材的書可能要手動處理不少段落；**自動跨供應商**：內容會在沒特別同意下送到第二家；都否決。
