# ADR-0058：本機資料的保留與刪除

## 脈絡

驗證規則會改，翻譯記憶是花錢買來的，但這些資料都含書籍內容。

## 決定

1. LLM 原始回應保留在 `book.db`，驗證規則改了可以免費重跑。
2. `tome purge <book>` 刪 IR、`book.db`、系列記憶裡這本書的項目，並清掉遠端殘留的批次。
3. 不動 PDF 與 vault，加 `--vault` 才刪 vault，執行前列出清單要確認。
4. `tome backup` 匯出資料庫與實體卡，不含 PDF。

## 後果

`book.db` 較大。備份檔含書籍內容，要由使用者放在安全的地方。

## 替代方案

**只留譯文**：驗證邏輯改了就要重付；**purge 保留系列記憶**：書的片段留在工作區；**連 vault 一起刪**：容易誤刪成果；都否決。
