# ADR-0049：規則包正則的防護

## 脈絡

規則包的正則會跑在書的文字上，寫壞的回溯可能卡死整個流程。`re2` 是原生模組，不支援 lookahead，V8 線性引擎還是實驗性質。

## 決定

1. 用 JavaScript 內建正則。
2. 模式在 worker thread 執行並設時限，卡住就終止並回報是哪個模式。
3. `tome system lint` 抱怨危險寫法。

## 後果

限時會拖慢一點，效果待驗證（H-16）。

## 替代方案

**`re2`**：線性時間，但要處理原生模組，也不支援部分語法；否決。
