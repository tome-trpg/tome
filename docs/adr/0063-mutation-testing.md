# ADR-0063：關鍵模組的變異測試

## 脈絡

覆蓋率高不代表測試抓得到錯誤。全專案跑變異測試又太慢。

## 決定

1. Stryker 跑遮蔽還原、驗證、翻譯記憶鍵、預算、對外出口、狀態機六個模組。
2. 排程執行，不在每次 CI 跑。
3. 分數門檻等第一次實測後再定。

## 後果

其他模組沒有這層保護。

## 替代方案

**全專案設門檻**：很慢，也花力氣在不重要的程式上；**只看覆蓋率**：不能證明測試有用；都否決。
