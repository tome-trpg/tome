# ADR-0022：原書頁碼參照

## 脈絡

規則書裡的「見 p.42」寫的是印刷頁碼。帶團時要能點過去，也要能對回實體書。

## 決定

1. 參照輸出成可點的連結，顯示 `（參見原書 p.42）`。
2. 解析不到時留純文字 `（參見原書 p.42）`。
3. 每頁邊界注入 `<!-- page: 42 -->`，預覽看不到，用來對回實體書。

## 後果

要維護實體頁與印刷頁碼的對應表。

## 替代方案

**只留文字**：帶團時點不過去；**只用連結**：對不回實體書；都否決。
