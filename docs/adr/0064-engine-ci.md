# ADR-0064：引擎測試走獨立工作流程

## 脈絡

Docling 要下載大型相依與權重，不適合每次 CI 都跑。

## 決定

1. 平常的 CI 用錄好的引擎輸出測轉接與組裝。
2. 改到 `engines/` 或手動觸發時，才安裝 Docling 跑合成 PDF。

## 後果

Docling 升級造成的問題可能晚一點才發現，靠版本鎖定與手動觸發補。

## 替代方案

**每次都跑**：最早發現問題，但每次 CI 都要下載大型相依；否決。
