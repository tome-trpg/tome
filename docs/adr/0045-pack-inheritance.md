# ADR-0045：規則包單一繼承，一本書一個包

## 脈絡

同一個引擎的遊戲共用術語與骰子規則，重抄一份之後要改很多地方。多重組合則要定義衝突規則。

## 決定

1. 規則包用單一 `extends`，子包覆寫父包。
2. 一本書只套一個規則包，要混合就寫一個小包繼承主包。

## 後果

繼承鏈要能追查，所以有 `tome glossary why`。

## 替代方案

**不繼承**：修一個模式要改很多包；**多重組合**：衝突規則複雜；都否決。
