# ADR-0013：預設單次翻譯，校稿依角色開啟

## 脈絡

全書校稿至少讓成本翻倍，而查到的研究不足以支持（[佐證 §1.9](../research/2026-10-31-landscape.md#19-標籤協定與佔位符的前例)）。

## 決定

1. 預設翻一次加零 token 驗證。
2. LLM 校稿只開在規則包指定的角色上。

## 後果

品質主要靠模型選擇與驗證。

## 替代方案

**全書校稿**：成本至少翻倍；**不做校稿 pass**：之後要加得改流程；都否決。
