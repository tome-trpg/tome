# ADR-0012：vault 可直接修改，tome sync 回收

## 脈絡

帶團時看到錯字會順手改，這些修改不能在下次輸出被蓋掉。

## 決定

1. vault 可以直接修改。
2. `tome sync` 比對上次輸出與目前的 vault，把改過的段落存成人工譯文。
3. 人工譯文優先序最高，不會被覆蓋。
4. 併段、拆段這類結構改動回收不了，列在交付報告裡。

## 後果

工作區要保存上次輸出與段落對應。

## 替代方案

**只改雙語校對檔**：實作簡單，但帶團時不能順手改；否決。
