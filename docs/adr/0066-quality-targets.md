# ADR-0066：品質目標與第一版完成條件

## 脈絡

G-1 的「上桌品質」要有可以量的定義，第一版也要有明確的終點。

## 決定

1. 採用白皮書 §10 的 Q-1 到 Q-9，全部是目標，尚未量測。
2. 盲評門檻是平均 4 分以上，且不輸舊專案的譯文，舊譯文只在本機對照。
3. 第一版的完成條件：公開的 ORC 文件一章，加本機商業書一章，全流程跑完，Q-1 到 Q-8 達標。

## 後果

Q-4、Q-5、Q-6、Q-9 的數字是初值，第一次實測後可能調整。

## 替代方案

**不跟舊專案比**：較單純，但少了最實際的基準；**整本書跑完**：要花一本書的 API 費；**只要公開素材**：驗不到真實的雙欄與邊欄；都否決。
