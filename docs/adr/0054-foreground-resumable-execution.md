# ADR-0054：前景執行，可中斷續跑

## 脈絡

Batch 多數在 1 小時內完成，但電腦不該因此一直開著。常駐服務對 CLI 工具太重。

## 決定

1. `tome translate` 在前景送批次並輪詢，Ctrl-C 不遺失進度。
2. 之後再執行一次，或用 `tome batch collect` 收回。
3. 沒有常駐服務。
4. 批次提交先寫入意圖紀錄，再呼叫 API，避免當機後重複付費。
5. 每本書同時只跑一個流程。

## 後果

要記得回來收結果。意圖紀錄是否足以防重複付費待驗證（H-17）。

## 替代方案

**背景常駐服務**：多一個要安裝、更新、除錯的服務；否決。
