# ADR-0033：預設 Batch，收完刪除遠端資料

## 脈絡

Batch 固定省 50%，但輸入與輸出會在供應商端保留 29 到 42 天，也不適用 ZDR。三家都提供刪除 API（[佐證 §1.10](../research/2026-10-31-landscape.md#110-第-4-輪補充)）。

## 決定

1. 預設用 Batch。
2. 結果收回並驗證後，MUST 呼叫供應商的刪除 API。
3. 估價時顯示資料保留時間。
4. 每章一批，過大再拆，每批送出前檢查預算。

## 後果

要等結果，全書較慢，快取要跨批次維持。刪除後多久真正清除未確認。

## 替代方案

**預設即時**：費用是兩倍；**整本書一批**：要到最後才知道品質，也無法中途擋預算；都否決。
