# ADR-0041：不內建預設模型

## 脈絡

便宜模型的 zh-TW 品質還沒驗證（H-2），內建預設等於替使用者選了沒有證據的模型，也可能在沒注意時花到貴的模型。

## 決定

1. TOME 不內建預設模型。
2. `scanner_model`、`translator_model` 必填，可以依區塊角色覆寫。
3. 範本列出建議組合，並註明還沒有盲評。

## 後果

第一次使用要多寫設定。

## 替代方案

**內建預設，可覆寫**：開箱即用，但沒有品質證據，模型改版時也要跟著發版；否決。
