# ADR-0036：快取依實測決定

## 脈絡

輸出費約占八成，快取碰不到這一塊。Batch 上開 1 小時快取，命中率低於約 51% 反而比不開貴，而文件列的觀測值是 30 到 98%（附錄 A）。

## 決定

1. 靜態前綴一律保持位元組一致。
2. 不為了跨門檻灌水。
3. 詞庫只送命中的詞條與活躍實體，放動態部分。
4. 試翻量到的命中率高於損益兩平點，才開 1 小時快取與預熱。
5. Gemini 預設走隱式快取。

## 後果

跟 prompt 的靜態前綴設計不同，要靠試翻才知道開不開。

## 替代方案

**一律開啟**：命中率低時反而較貴；**一律不開**：放棄最多約 34% 的節省；都否決。
