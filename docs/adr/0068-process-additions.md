# ADR-0068：流程補充項目

## 脈絡

假說沒驗證就容易被當成事實。效能與供應鏈問題也不該等使用者回報。

## 決定

1. 白皮書 §11 每條假說對應一個測試或評測項目，沒驗證就不能標成已實作。
2. 效能預算進 CI，變慢時會失敗。
3. 公開語料的評測結果放 `docs/evals/`，商業書的結果不公開。
4. CI 加 `npm audit`，並檢查相依授權都在 ADR-0043 的白名單內。

## 後果

效能預算在 CI 機器上會有波動，門檻要留餘裕。

## 替代方案

**不公開評測結果**：範本不內建預設模型後，使用者選模型就沒有證據；否決。
