# ADR-0039：對外請求走單一模組

## 脈絡

G-5 要求合規是結構，不是紀律。個資閘門與端點白名單只要漏一個呼叫點，就是外流。

## 決定

1. 所有對外網路請求 MUST 走單一模組，其他程式不得自己連網。
2. 個資閘門與端點白名單都在這裡。
3. 本機留外送紀錄，只記內容雜湊、供應商、模型、大小與時間。
4. OpenRouter 一律送 `data_collection: deny`。

## 後果

多一層，但斷言可以把關。

## 替代方案

**閘門照做，不限制模組**：要靠紀律，漏一個就是外流；否決。
