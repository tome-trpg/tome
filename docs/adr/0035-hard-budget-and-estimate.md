# ADR-0035：預算硬上限與本機估價

## 脈絡

G-3 要求先知道花多少再花錢。各家的計數 API 準確，但估價階段就要把全書送出去。

## 決定

1. 預算是必填的硬上限，沒設就不開跑。
2. 估價後要確認，每批送出前用實際花費檢查，重試與回退都計入，超過就停並保留進度。
3. 估價在本機完成，依字元數與各家比例估算，顯示成區間。
4. `tome trial` 先翻一小段，用實際 `usage` 校準，人工改動回饋成風格範例。

## 後果

第一次估價誤差較大。

## 替代方案

**選填上限**：忘記設就沒有保護；**只顯示估價**：與 G-3 不一致；**用各家計數 API**：開跑前就把書送出去；都否決。
