# ADR-0072：合併規則

## 脈絡

spec-harness 的回合稽核以分支為單位。維護者的慣例是閘門綠了就合併。

## 決定

1. 白皮書討論階段維持直接推送 `main`。
2. 從第一個實作回合起，程式走 PR，CI 通過後由代理人合併。
3. `main` 的 ruleset 要求 PR 與 CI，第一個實作回合才打開。
4. `v*` 標籤只有維護者能推。

## 後果

ruleset 要維護者在網頁上設定。

## 替代方案

**每個 PR 都由維護者審核**：回合多時會卡住；**繼續直接推送**：回合稽核用不上；都否決。
