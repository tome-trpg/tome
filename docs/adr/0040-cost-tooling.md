# ADR-0040：成本工具

## 脈絡

花費要能事前檢查、事後對帳。Gemini 在 2026-12-01 與 2027-01-01 都會調價，價格不能寫死。

## 決定

1. `--dry-run` 組出所有請求但不送出。
2. 價目表放資料檔，帶生效日與查證日，過期就警告。
3. 費用帳本記下每個單位的實際 `usage` 與花費。
4. 開了快取卻連續沒命中就停下來警告。
5. 文件建議在供應商後台設花費上限、用專用金鑰、DeepSeek 排在離峰。

## 後果

價目表要隨發版維護。

## 替代方案

**不做這些工具**：花費只能事後看帳單；否決。
