# ADR-0025：預設只走 API，本機模型不承諾

## 脈絡

本機模型來自初版 prompt，維護者預設接 API。OpenAI 相容協定本來就要做給 OpenRouter 用。

## 決定

1. 預設只走 API。
2. 本機 OpenAI 相容端點接得上，但不測試也不承諾，沒有參考 runtime。

## 後果

不再需要模型能力宣告，也不必處理翻譯專用模型的限制。

## 替代方案

**完全不支援本機**：反而要多寫檢查；**保留成正式功能**：要選參考 runtime，測試量加大；都否決。
