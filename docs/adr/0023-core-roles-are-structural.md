# ADR-0023：核心角色只描述文件結構

## 脈絡

有些 TRPG 沒有 GM，核心不能預設守密人這類概念。數值塊、handout 同樣是遊戲概念，引擎核心不含遊戲知識（G-2）。

## 決定

1. 核心角色只描述文件結構：標題、段落、清單、表格、邊欄、圖片、註腳、目錄、索引、版權頁、頁面雜訊。
2. 遊戲概念與實體類別都由規則包宣告，帶命名空間。
3. `generic` 包提供最常見的幾種。

## 後果

第 5 輪的規則包規格要涵蓋角色與實體類別。

## 替代方案

**保留 `stat_block` 與 `handout` 在核心**：核心就不是完全沒有遊戲知識；否決。
