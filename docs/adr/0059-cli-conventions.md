# ADR-0059：CLI 慣例

## 脈絡

訊息是繁中，機器要有別的方式讀結果。之後代理人也要能操作。

## 決定

1. `tome status` 顯示進度、批次、花費與下一步。
2. `tome doctor` 檢查 Node、uv、金鑰、引擎、工作區與價目表。
3. `--json` 給機器讀，結束碼是 0 正常、1 有發現、2 結果不可信，跟 spec 工具一致。
4. 設定優先序是旗標、環境變數、單書、工作區，設定檔 MUST NOT 放秘密。
5. 紀錄檔 MUST NOT 含書本文字。

## 後果

`--json` 的格式成為對外介面，改動要有版本。

## 替代方案

**只有人讀的輸出**：腳本與代理人沒辦法用；否決。
