# ADR-0050：規則包工具

## 脈絡

ORC 的聲明寫漏會讓授權自動終止，不該靠人記得。層次變多後，譯名錯誤也要查得到來源。

## 決定

1. `tome system test` 驗證模式，不花 token，公開包必備。
2. `tome system lint` 檢查 schema 與危險正則，公開包另查授權與聲明，由 CI 把關。
3. 翻譯記憶的風格版本用該角色風格文字的雜湊，不用規則包版本號。
4. `tome glossary why <詞>` 顯示譯名來自哪一層。

## 後果

公開包要多維護測試。

## 替代方案

**只靠人工檢查**：聲明寫漏的代價太高；否決。
