# ADR-0105：0.1.0 發佈前請著作權律師審查

## 脈絡

維護者問使用 TOME 會不會算犯罪。2026-11-02 比較了十三個法域對這個情境的規定：使用者把自己合法購買的書在本機解析，分段送到雲端 LLM API 翻譯，只供自己使用、不散布。

結果是每個法域都沒有找到判決或主管機關見解直接處理這個情境，所有評價都由條文與相鄰案件推出。最大的缺口在雲端那一段，私人例外預設由使用者自己動手，模型卻在服務商的機器上完成翻譯。台灣第 51 條的「非供公眾使用之機器」沒有函釋，智慧局的代客掃描見解只能類推。比較報告不是法律意見。

下列決定由維護者在 2026-11-02 選定。

## 決定

1. 0.1.0 發佈前 MUST 請著作權律師看過比較報告，重點是雲端 API 這一段。這是 M4 的項目，修改 ADR-0080 的第一版範圍。
2. 比較報告放在 `docs/research/2026-11-02-personal-translation-law.md`，是查證紀錄，不是法律意見。之後的改動走新的查證紀錄。
3. 報告保留日文的條號與案名原文，含 Big5 以外的日文字形，所以依 ADR-0086 第 5 項列入文字檢查的例外清單。

## 後果

發佈多一道外部審查，時程與費用都還沒估。報告列了還沒查到的項目：德國 § 53 的註釋書、台灣法院判決與認定要點、韓國主管機關的解釋、法國 2016 年之後的見解，也列了值得追的事件，例如智慧局指引 1.0 是否公告。

## 替代方案

**不請律師，只靠查證紀錄**：沒有判決可依，公開工具的使用者只能看專案自己的判斷；**現在就請律師**：翻譯流程還沒完成，事實還會變；**報告不進 repo**：查證結果只留在本機，之後的人重查一次；**把日文字形改成繁體**：條號與文件名稱會失真，無法照原文查；都否決。
