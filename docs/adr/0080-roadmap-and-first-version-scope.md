# ADR-0080：路線圖與第一版範圍

## 脈絡

ADR-0029 列的項目不必全進第一版。先做解析，因為解析錯了翻譯再好也沒用，而且這一段不花 API 費。

## 決定

1. 路線分五個階段：M0 基礎、M1 解析、M2 翻譯核心、M3 譯名與輸出、M4 首版。
2. 0.1.0 只接 Anthropic，只附 `generic` 與 `d100-orc`。
3. 0.1.0 包含：同組單位不跨批次、活躍實體、新詞回報、`keep_source` 與比對條件、不可譯旗標、單位不換算、審定分級、譯後自動排版、交付報告、全書提要、`--dry-run`、費用帳本、`tome sync`、數值塊欄位化、一致性報告、`tome glossary import`。
4. 排到 0.1.0 之後：`tome system init`、系列詞庫與共用翻譯記憶、新版差異更新、`gumshoe-srd`。`series.db` 的結構先留好，之後不用改格式。
5. OpenAI 相容協定、Gemini、日文與簡中來源都在 0.1.0 之後。

## 後果

第一版要用品牌系統的書時，規則包靠 `d100-orc` 或 `tome system new` 手寫。

## 替代方案

**先做翻譯核心**：最快看到譯文，但解析問題會晚很多才暴露；**四項都進第一版**：功能最完整，但首版明顯變晚，測試面也變大；都否決。
