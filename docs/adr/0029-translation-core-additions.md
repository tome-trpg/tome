# ADR-0029：翻譯核心的補充項目

## 脈絡

第 3 輪提案後再比對 prompt 與實際使用情境，找出這些缺口。其中「同組單位不跨批次」是 prompt 的要求，翻譯單位細到儲存格後被漏掉。

## 決定

1. 同一個表格、邊欄或群組的單位不跨批次。
2. 活躍實體上下文。
3. 主翻譯回報新詞，進入審定佇列。
4. 全書一致性報告。
5. 實體卡的 `keep_source` 與比對條件。
6. 不可譯旗標。
7. 單位不換算。
8. 系列詞庫與共用翻譯記憶。
9. `tome glossary import`。
10. 審定分級。
11. 譯後自動排版。
12. 統一交付報告。
13. 全書提要。
14. 靠內容雜湊做新版差異更新。

## 後果

第一個切片的範圍要在第 9 輪重新切，這些不必全部進第一版。

## 替代方案

**只留必要項**：譯名分裂與誤報的風險留給使用者；否決。
