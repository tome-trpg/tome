# ADR-0075：開放貢獻，嚴禁貼書籍內容

## 脈絡

PC-1 不准商業書進 repo，這要延伸到 Issue 與 PR。規則包作者也要能貢獻。

## 決定

1. 開放 Issue 與 PR。
2. 不需要 CLA，貢獻依 Apache-2.0 授權，規則包目錄依各自的授權。
3. Issue 與 PR 範本明寫不得貼商業書的文字、譯文或截圖，回報問題用合成範例。

## 後果

要處理違規內容，必要時刪除。

## 替代方案

**只開放 Issue**：規則包作者無法直接貢獻；**第一版前不開放**：repo 是公開的，反而要多解釋；都否決。
