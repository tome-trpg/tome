# ADR-0017：購買者浮水印定位成個資遮蔽

## 脈絡

台灣著作權法 §80-1 禁止移除權利管理電子資訊，§96-1 有刑責；購買者姓名是否屬於該定義查不到見解（[佐證 §3.2](../research/2026-10-31-landscape.md#32-著作權)）。這不是法律意見。

## 決定

1. 購買者姓名、訂單號不進譯文，也不送 LLM。
2. 來源 PDF 不修改，TOME 不輸出修改過的 PDF。
3. 書名、作者、版權頁等權利資訊保留在來源紀錄。
4. 文件與 CLI 不使用「去浮水印」的說法。
5. 送出前再比對使用者設定的個資清單，還有命中就停。

## 後果

使用者要維護個資清單。

## 替代方案

**只過濾不設閘門**：漏掉的個資會直接送出；**照 prompt 叫浮水印剝離**：法律風險較高；都否決。
