# ADR-0067：測試補充項目

## 脈絡

G-4 與數字零錯誤是硬承諾，要有直接證據。提示一改，品質可能悄悄變動。

## 決定

1. 當機注入測試：在狀態機每一步強制中斷再續跑，驗證沒有單位重付。
2. 用 fast-check 驗證遮蔽再還原一定回到原樣。
3. 提示回歸：改提示或風格時，用黃金段落小額重跑並列出差異。
4. 每筆譯文記下提示雜湊、規則包雜湊、模型與 SDK 版本。

## 後果

提示回歸要花少量費用。

## 替代方案

**只靠單元測試**：證明不了續跑不重付；否決。
