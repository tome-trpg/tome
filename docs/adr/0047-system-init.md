# ADR-0047：tome system init 用本機統計加抽樣 LLM

## 脈絡

ADR-0001 要使用者從自己的書產生品牌規則包，prompt 要抽樣分析並產出草稿。

## 決定

1. 先在本機統計骰子格式、重複版面、高頻術語。
2. 再抽樣幾十頁送 `scanner_model`，提議角色、術語與文風，受預算與個資閘門管制。
3. 產出草稿放在工作區，由人審定後才能使用。
4. `tome system new` 產生空白骨架。

## 後果

抽樣可能漏掉少見的數值塊，靠 `tome trial` 補。

## 替代方案

**完全本機**：文風與角色要自己寫；**掃描整本書**：成本最高，也跟 Pass 0 重複；都否決。
