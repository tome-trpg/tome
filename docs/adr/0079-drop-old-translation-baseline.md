# ADR-0079：盲評門檻不再跟舊譯文比較

## 脈絡

ADR-0066 要求盲評平均 4 分以上，且不輸舊專案的譯文。舊譯文已經刪除，舊流程也移除了，無法重建，這個基準不存在了。

## 決定

1. 盲評門檻改成平均 4 分以上，取代 ADR-0066 的「不輸舊專案」。

## 後果

少了一個實際的對照組，門檻完全靠維護者的絕對判斷。

## 替代方案

**重新翻一次當基準**：要重建舊流程並花一本書的費用，只為了留一個過時的對照；否決。
