# TOME

TOME（TRPG Omnilingual Markdown Engine）是在本機執行的命令列工具，用來解析使用者自有的 TRPG 書籍，並以使用者自備的 LLM API 金鑰翻譯成繁體中文。

[English](README.en.md)

> [!IMPORTANT]
> **專案狀態：開發中，尚未發布**。目前已完成基礎架構與部分解析功能，尚無翻譯功能，npm 上也只有不含程式的預留版本。各項功能的進度請參閱[開發進度](#開發進度)。

## 專案概述

一般的 PDF 翻譯工具並非針對 TRPG 書籍設計，常見的問題包括：

* 雙欄與側欄版面使閱讀順序錯亂。
* `1D100` 這類骰子標記或數值在翻譯時遭到更動，導致規則內容出錯。
* 同一個角色或專有名詞在全書出現多種譯名。

TOME 的設計目標是解決這些問題，並讓譯文可以直接用於實際遊戲。

## 主要功能

下列功能為設計目標，實作情形請參閱[開發進度](#開發進度)。

| 功能 | 說明 |
| :--- | :--- |
| 本機解析 | PDF 與頁面影像只在本機處理，不會離開使用者的電腦。對外傳送的只有經過遮蔽的文字。 |
| 骰子與數值保護 | 翻譯前先遮蔽骰子標記與公式，翻譯後再以不消耗 token 的驗證程序檢查數字是否一致。 |
| 譯名一致 | 翻譯前先擷取專有名詞，影響較大的名詞由人工審定後才開始翻譯。 |
| 費用控管 | 開始翻譯前先在本機估算費用。使用者必須設定預算上限，達到上限即停止。 |
| 中斷後繼續 | 流程可隨時中斷，已通過驗證的段落不會重複計費。 |
| Obsidian 相容 | 輸出 Obsidian 相容的 Markdown，在 Obsidian 修改的內容也能匯回 TOME。 |
| 零遙測 | 不蒐集使用統計，也不自動檢查更新。TOME 的對外連線僅限兩種情況：呼叫使用者設定的 LLM API，以及安裝解析引擎時下載所需檔案。 |

## 開發進度

| 功能 | 指令 | 狀態 |
| :--- | :--- | :--- |
| 建立工作區、檢查環境 | `tome init`、`tome doctor` | 已實作 |
| 設定 API 金鑰 | `tome provider auth set` | 已實作 |
| 登記書籍、探測 PDF | `tome add`、`tome probe` | 已實作，並可依規則包的資料建議適用的規則包 |
| 管理規則包 | `tome system new`、`list`、`lint`、`test` | 已實作，內建 `generic` 規則包 |
| 管理解析引擎 | `tome engine add`、`list`、`remove` | 已實作 |
| 解析頁面 | `tome extract` | 已實作：將原生文字頁交給解析引擎，組裝成文件，並檢查字元是否遺失 |
| 重新驗證譯文 | `tome verify` | 已實作，翻譯功能完成後才有回應可驗證 |
| 估算費用 | `tome estimate`、`tome translate --dry-run` | 已實作：在本機估算，不連網，估算比例尚未校準 |
| 翻譯與輸出 | 尚未提供 | 規劃中 |

## 不涵蓋的範圍

下列事項不在 TOME 的範圍內：

* 提供書籍內容或散布譯文。
* 繞過 DRM。所有加密的 PDF 一律拒絕處理。
* 修改來源 PDF，或輸出 PDF。
* 提供線上服務。

TOME 僅用於處理使用者自有的書籍。譯文僅供個人使用，不得散布。

## 系統需求

* Node.js 24 以上。
* [uv](https://docs.astral.sh/uv/)：僅在安裝解析引擎時需要。

## 安裝

TOME 尚未發布正式版本。第一個正式版本發布後，可用下列指令安裝：

```bash
npm install -g tome-trpg
```

> [!WARNING]
> 請勿執行 `npx tome`。npm 上的 `tome` 是其他作者的套件，與本專案無關。
