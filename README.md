# TOME

**TRPG Omnilingual Markdown Engine**：把你自己擁有的 TRPG 書在本機解析，用你自己的 LLM API 金鑰翻成能直接上桌的繁體中文。

[English](README.en.md)

> **狀態：規劃中。** 目前只有白皮書與決策紀錄，還沒有程式碼，也還不能安裝。

## 這是什麼

一般的 PDF 翻譯工具不懂 TRPG：雙欄與邊欄會打亂閱讀順序，`1D100` 被改一個字元規則就錯了，同一個 NPC 在四百頁裡會有好幾個譯名，神祇該用「祂」也不會有人告訴模型。TOME 要解決的是這些問題。

* **本機解析**：PDF 與頁面影像不會離開你的電腦，送出去的只有遮蔽過的文字。
* **骰子與數字零錯誤**：先遮蔽再翻譯，翻完用不花 token 的驗證檢查。
* **譯名全書一致**：先抽出專有名詞，高影響的由人審定後才開始翻。
* **先知道花多少**：開跑前在本機估價，預算是必填的硬上限，超過就停。
* **隨時可中斷**：已通過驗證的段落絕不重付。
* **輸出給帶團用**：Obsidian 相容的 Markdown，在 Obsidian 改的字也收得回來。
* **零遙測**：沒有使用統計，也不自動檢查更新。TOME 只連你設定的 LLM API，以及安裝解析引擎時的下載。

設計與理由都在[白皮書](docs/WHITEPAPER.md)，每個決策在 [docs/adr](docs/adr)。

## 這不是什麼

* 不提供任何書籍內容，也不散布譯文。
* 不繞過 DRM，加密的 PDF 一律拒絕。
* 不修改來源 PDF，也不輸出 PDF。
* 不是線上服務。

TOME 是給你處理**自己擁有**的書。譯文只供你自己使用，不得散布。

## 安裝

第一版發佈後會是：

```bash
npm install -g tome-trpg
```

需要 Node 24 以上。安裝解析引擎還需要 [uv](https://docs.astral.sh/uv/)。

**不要執行 `npx tome`。** npm 上的 `tome` 是別人的套件，跟這個專案無關。
